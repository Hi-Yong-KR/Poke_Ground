포켓몬 그라운드 (PokeGround) - 오프라인 배포판

[실행]
  1. 받은 zip 파일의 압축을 풉니다. (zip 안에서 바로 실행하면 안 돼요)
  2. 풀린 폴더의 start.bat 을 더블클릭합니다.
     인터넷, 프로그램 설치, 관리자 권한 모두 필요 없습니다.
  * 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]을 누르세요.

[사용법]
  - 화면 오른쪽 아래 몬스터볼을 누르거나 Ctrl + Alt + Space 로 명령창을 엽니다.
  - 말하거나 입력하세요:  "피카츄 크롬 10만볼트",  "꼬부기 휴지통 물대포",  "모두 이리와"
  - 포켓몬을 클릭, 드래그, 쓰다듬기(마우스로 문지르기)로 놀아 줄 수 있어요.
  - 처음엔 피카츄 한 마리가 나와요.
  - [파티] 버튼: 포켓몬 980여 마리가 도감 번호순으로 다 나와요. 이름이나 번호로 찾을 수도 있어요.
    누르는 대로 바로 내보내고 들여보내요. (여러 마리를 한 번에, 따로 받을 필요 없음)
  - [+ 포켓몬] 버튼: 그림이 아직 안 들어 있는 포켓몬은 여기서 찾아 [받아서 내보내기]를
    누르면 그때 받아 옵니다. (이때만 인터넷 필요)
    [내 그림으로 추가]에서 가진 그림(PNG, GIF, JPG 한 장 또는 PMD 스프라이트 zip, 폴더)으로
    도감 포켓몬이나 나만의 캐릭터를 만들 수도 있어요.
    PMD 스프라이트는 SpriteCollab 제출 형식 그대로 됩니다. 스프라이트 zip과 초상화 시트
    (portrait-XXXX.png)를 따로 갖고 있으면 Ctrl을 누른 채 둘을 함께 고르세요.
  - 시계 옆 트레이의 피카츄 아이콘 우클릭: 명령창 열기, 음성인식 켜기/끄기, 종료
  - 음성인식은 인터넷 없이 이 PC 안에서만 처리됩니다.

[필요 사양]
  Windows 10(1809 이상) 또는 11, 64비트 / 메모리 4GB 이상 권장 / 디스크 약 1.5GB

[지우기]
  트레이 메뉴에서 종료한 뒤 폴더를 지우면 됩니다. (설정은 %APPDATA%\poke-ground 에 남아요)
