# 포켓몬 그라운드 (PokeGround)

바탕화면 위를 포켓몬이 자유롭게 돌아다니는 Windows 데스크탑 앱입니다.
클릭·드래그·쓰다듬기로 놀아주고, **음성 또는 텍스트**로 "피카츄 크롬 10만볼트!"처럼 명령하면
화면에 실제로 떠 있는 창이나 바탕화면 아이콘을 찾아가 기술을 씁니다.

## 내려받아 바로 쓰기

[Releases](https://github.com/Hi-Yong-KR/Poke_Ground/releases/latest)에서 **PokeGround-offline.zip** 을 받아 압축을 풀고, `PokeGround\start.bat`을 더블클릭하면 끝입니다. 인터넷·설치·관리자 권한 모두 필요 없어요. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.

## 소스에서 실행

`start.bat`을 더블클릭하세요. 처음 실행할 때 필요한 것을 자동으로 설치하고 받아옵니다(인터넷 필요, 첫 실행 몇 분).
따로 설치할 것은 없습니다. Node.js와 파이썬은 PC에 있으면 그걸 쓰고, 없으면 이 폴더 안(`.node`, `.python`)에만 따로 받아 씁니다 (관리자 권한 필요 없음, 폴더를 지우면 함께 사라짐). 준비하다 실패하면 창에 이유를 보여 주고 멈춥니다.
다른 PC에 옮길 때는 `node_modules`, `.node`, `.python`, `.venv` 폴더는 빼고 복사해도 됩니다 (첫 실행 때 다시 받음).

- **필요한 것**: Windows 10(1809 이상)/11 64비트, 첫 실행 때 인터넷(모두 합쳐 약 0.8GB).
- 음성인식 엔진이 쓰는 **Microsoft Visual C++ 런타임**이 PC에 없으면 Microsoft 공식 설치 파일을 받아(서명 확인) 설치합니다. 이때 **관리자 확인 창이 한 번** 뜹니다. "아니요"를 누르면 예비용 음성인식(Vosk)으로 대신합니다.

### 인터넷 없는 PC에 배포 (오프라인 배포판)

인터넷이 되는 PC에서 한 번 만들어 두면, 받는 PC는 **압축만 풀고 `start.bat`** 으로 바로 실행합니다. 인터넷·Node.js·파이썬·관리자 권한 모두 필요 없습니다.

```bash
npm run make-offline
```

- 결과: `dist\PokeGround-offline.zip` (약 0.9GB, 풀면 1.4GB) — Electron 본체, 휴대용 파이썬 + faster-whisper, Visual C++ 런타임 DLL, Whisper 모델, 스프라이트(포켓몬 980여 마리 전부)가 들어 있습니다.
- 울음소리(게임 원음)는 저작권 때문에 zip에 넣지 않고, 앱이 처음 실행될 때 인터넷이 되면 받아 둡니다(아래 참고). 인터넷이 없는 PC에서도 처음 27마리가 울게 하려면 `powershell -File scripts\make-offline.ps1 -IncludeCries` (개인·비상업적 용도로만).

```bash
npm install
npm run setup
npm start
```

- 실행하면 작업표시줄 대신 **트레이(시계 옆)에 피카츄 아이콘**이 생깁니다. 우클릭 메뉴에서 명령창 열기, 음성인식 켜기/끄기, 종료를 할 수 있어요.

### 포켓몬 (980여 마리)

처음 실행하면 피카츄 한 마리가 나옵니다. 명령창의 **🎒 파티**를 열면 그림이 들어 있는 포켓몬 980여 마리가 도감 번호순으로 모두 나와요. 따로 받거나 추가할 필요 없이, 초상화를 누를 때마다 바로 화면에 나오거나 몬스터볼로 들어갑니다. 창은 닫히지 않아서 여러 마리를 한 번에 고를 수 있어요.

- 이름(`파이리`, `gengar`)이나 도감 번호(`94`, `#150`)로 찾을 수 있어요. **전부 들여보내기**를 누르면 화면의 포켓몬(검색 중이면 찾은 것만)이 모두 몬스터볼로 돌아가요.
- 한 번 내보낸 포켓몬은 음성·텍스트 명령("파이리 크롬 화염방사", `님피아 나와`)으로도 부를 수 있어요.
- 각자 타입에 맞는 기술 4~5개를 쓰고, 못 배우는 기술을 시키면 거절해요. 기술 연출이 없는 타입(독·땅·벌레·고스트)은 비슷한 타입(악·바위·풀) 기술을 씁니다.
- 배포판에 그림이 없는 포켓몬(만들 때 PMD SpriteCollab에 아직 그림이 없던 45종 등)은 **＋ 포켓몬**에서 찾아 **[받아서 내보내기]** 를 누르면 그때 그림을 받아 옵니다(인터넷 필요). 받은 그림은 `%APPDATA%poke-grounddex`에 남아요.
- **울음소리**: 처음 실행할 때 인터넷이 되면 전국도감 1025종의 울음소리(약 17MB)를 한 번 받아 `%APPDATA%\poke-ground\cries`에 둡니다. 명령창에 "울음소리를 받는 중" → "받았어요"가 표시돼요. 인터넷이 없으면 다음 실행 때 다시 받아요.

### 내 그림으로 추가 (도감 포켓몬·창작 캐릭터)

같은 **＋ 포켓몬** 창의 **내 그림으로 추가**에서 직접 가진 그림으로 포켓몬을 만들 수 있어요. 인터넷이 필요 없습니다.

1. **그림·zip 고르기** 또는 **PMD 폴더**로 그림을 고릅니다.
   - **이미지 한 장** (PNG·GIF·WebP·JPG): 아무 그림이나 됩니다. 화면에서 키 72px 정도로 맞추고, 걸을 때 통통 튀기·기술 쓸 때 쑥 커지기·숨쉬기 같은 움직임을 앱이 붙여 줘요. 움직이는 GIF는 그대로 움직입니다. 그림은 왼쪽을 본다고 보고, 오른쪽으로 갈 때 뒤집어요.
   - **PMD 형식 스프라이트** (zip 또는 폴더): `AnimData.xml`과 `Walk-Anim.png` 같은 애니메이션 파일이 든 것 — [SpriteCollab](https://sprites.pmdcollab.org)에서 받은 것이나 직접 만든 스프라이트. 다른 포켓몬처럼 걷기·공격·잠자기 동작이 모두 나옵니다. SpriteCollab에 제출하는 형식 그대로 넣으면 돼요.
     - **초상화**: SpriteCollab 형식의 **초상화 시트**(`portrait-XXXX.png`, 40px 칸 5×8)를 자동으로 감정별로 잘라 말풍선 얼굴로 씁니다. `Normal.png`, `Happy.png` 같은 감정별 파일도 됩니다. 없으면 얼굴 없이 말해요.
     - 스프라이트 zip과 초상화 시트를 따로 갖고 있으면 고르는 창에서 **둘을 함께**(Ctrl+클릭) 고르세요. 한 zip·폴더에 같이 넣어도 됩니다.
2. **이름**과 **타입**을 정하고 **추가**를 누릅니다. 타입에 맞는 기술을 쓰게 돼요.
   - 도감 이름을 그대로 쓰면(예: `시비꼬`) 그 포켓몬으로 보고 타입과 영어 이름을 맞춰 줍니다. 도감에 없는 이름이면 창작 캐릭터가 돼요.
   - 다른 포켓몬·기술·명령어와 겹치는 이름은 쓸 수 없어요.
3. 고른 원본 파일은 그대로 두고 `%APPDATA%\poke-ground\creations`에 복사해 씁니다. 삭제하면 이 복사본만 지워져요.
- **명령창**: 화면 오른쪽 아래 몬스터볼을 누르거나 `Ctrl + Alt + Space`. `Esc`로 닫습니다.
- 포켓몬이 없는 곳은 클릭이 그대로 뒤쪽 프로그램으로 전달되니 평소처럼 컴퓨터를 쓸 수 있어요.

## 명령 예시

| 명령 | 동작 |
|---|---|
| `피카츄 크롬 공격` / `피카츄 크롬 10만볼트` | 크롬 창(없으면 크롬 아이콘)을 찾아 🎯 표시 후 전기 기술 |
| `리자몽 윈도우탐색기 불대문자` | 탐색기 창 위에 '大' 모양 불꽃 |
| `꼬부기 클로드 물대포` / `하이드로펌프` | Claude 창에 물줄기 |
| `이상해씨 휴지통 솔라빔` | 휴지통 아이콘에 솔라빔 |
| `이브이 보고서 스피드스타` | 이름에 '보고서'가 들어간 아이콘/창을 찾아 공격 |
| `피카츄 꼬부기 공격` | 포켓몬끼리! (전기→물: 효과는 굉장했다!) |
| `피카츄 크롬 아이콘 공격` | '아이콘'을 붙이면 창보다 아이콘을 우선 |
| `모두 이리와` / `따라와` / `앉아` / `자` / `일어나` / `춤춰` / `점프` / `밥 먹자` | 일반 행동 |
| `잘했어` / `귀여워` / `안돼` / `안녕` / `놀자` / `멈춰` / `달려` | 칭찬·꾸중·인사 등 |
| `이브이 나와` / `피카츄 들어가` / `모두 들어가` | 몬스터볼에서 꺼내기 / 넣기 |
| `글레이시아 크롬 냉동빔` / `에브이 탐색기 사이코키네시스` / `블래키 휴지통 악의파동` | 얼음·에스퍼·악 등 새 타입 기술 |
| `피카츄 불대문자` | 못 쓰는 기술이면 "불은 못 뿜는다고 억울한 표정을 짓는다" |
| `리자몽 오늘 점심 뭐야` | 이해 못 하면 갸웃거리며 눈치를 봄 |

포켓몬은 대답 대신 **실제 울음소리**(기쁘면 높게, 슬프거나 혼나면 낮게)와 “피카피카!” 같은 글자, 감정 초상화, 그리고 **리액션 요약**(예: “고개를 끄덕인다. 대충 알겠다는 뜻 같다”)을 말풍선으로 보여줍니다.

인식하는 대상: 크롬, 엣지, 윈도우탐색기/탐색기/폴더, 클로드, VS코드, 메모장, 카톡, 한글, 워드, 엑셀, 파워포인트, 터미널, 휴지통, 내PC 등.
그 밖에도 창 제목이나 아이콘 이름 일부를 말하면 찾아갑니다.

## 상호작용 (40가지 이상 리액션)

- **클릭**: 27가지 리액션 중 무작위 (깡총, 빙글빙글, 부끄러움, 하품, 춤, 포즈, 간지럼, 귀찮음, 어지러움, 냠냠, 끄덕끄덕, 눈치, 힘자랑, 재채기, 사랑, 삐침, 기지개, 죽은 척, 점프, 인사, 꼬리 흔들기, 호기심, 기술 자랑, 꽈당, 둥실둥실, 앉기...)
- **더블클릭**: 높이 점프
- **연타**: 6번 이상 → 화냄, 8번 이상 → 울먹임
- **드래그**: 들어 올리면 발버둥, 놓으면 쿵! 어질어질
- **쓰다듬기**: 버튼을 누르지 않고 포켓몬 위에서 마우스를 문지르면 행복해함
- **잠자는 포켓몬 클릭**: 깨어나서 눈을 비빔
- 가만히 두면 스스로 돌아다니고, 앉고, 자고, 친구에게 다가가 놉니다.

## 음성과 텍스트

- 음성인식은 **인터넷 없이** 동작하는 **Faster-Whisper small** 모델을 씁니다. GPU 없이 CPU만 쓰고, 불러올 때 **INT8로 양자화**해서 메모리 약 0.5GB, 한 문장 인식에 1초 안팎이라 저사양 PC에서도 돌아갑니다(CPU 스레드는 최대 4개만 사용).
  - 처음 한 번 `npm run fetch-whisper`(start.bat이 자동 실행)가 `.venv` 파이썬 가상환경에 faster-whisper를 설치하고 모델(약 480MB)을 받습니다. 파이썬이 없으면 [uv](https://github.com/astral-sh/uv)로 파이썬 3.12(약 21MB)를 `.python`에 먼저 받습니다.
  - 소음에서 "피카츄"처럼 힌트 단어를 지어내는 Whisper 특성이 있어서, 인식 확신도가 낮은 결과는 버립니다.
  - 말소리가 들리는 구간만 잘라서 인식하고, 포켓몬·기술 이름을 힌트로 줘서 그 단어로 더 잘 받아씁니다. "피카츄야", "공격해"처럼 붙은 말은 명령 단어로 맞춰 읽어요.
  - Whisper 설치에 실패한 경우(인터넷 끊김 등)엔 예비용 Vosk 소형 모델(`npm run fetch-voice`)로 대신합니다. 지금 쓰는 엔진은 `⚙ 장치`에서 보여요.
- 주변 대화에 반응하지 않도록 음성 명령은 다음 조건을 모두 만족해야 실행됩니다. 걸러진 말은 로그에 `🎤 (명령 아님: 이유)`로 표시돼요.
  - **포켓몬 이름(또는 '모두')으로 시작** — "피카츄 크롬 공격" ⭕ / "크롬 공격해 피카츄" ❌
  - **짧게** (5단어 이하), **할 일은 한 가지** ("피카츄 점프 춤춰" ❌)
  - (Vosk일 때) 인식 신뢰도가 충분히 높을 것 (텍스트 명령에는 이런 제한이 없어요)
- 마이크가 없거나 모델이 없으면 자동으로 텍스트 전용으로 동작합니다.
- **장치 선택**: 명령창의 `⚙ 장치`에서 입력(마이크)과 출력(울음소리 스피커)을 고를 수 있어요. 입력 음량 막대로 마이크가 소리를 받는지 바로 보이고, `테스트`로 울음소리를 들어볼 수 있어요. **🔉 볼륨**으로 울음소리 크기를 정할 수 있어요(0%면 울지 않음). 고른 장치는 다음 실행 때도 기억하며, 그 장치가 빠지면 Windows 기본 장치로 대신 연결합니다.
- **텍스트 우선**: 음성 결과는 0.9초 기다렸다 실행되며, 다음 경우 음성은 버리고 텍스트를 따릅니다.
  - 명령창에 글자를 입력하고 있을 때 음성이 들어온 경우
  - 음성 대기 중에 텍스트를 입력하거나 제출한 경우
  - 텍스트 명령 직후(2.5초 이내) 음성이 들어온 경우

## 구조

```
src/main/main.js       Electron 메인: 투명 오버레이 창, 트레이, 단축키, 로컬 서버
src/main/whisper.js    음성인식 워커 관리 ─ whisper_worker.py: Faster-Whisper small(CPU INT8) 상주 프로세스
src/main/scanner.ps1   화면 객체 스캐너(상주 PowerShell) ─ scanner.cs: 창 목록·바탕화면 아이콘 좌표
src/shared/parser.mjs  명령 해석(한글 자모 퍼지매칭으로 오타/오인식 보정), 대상 찾기
src/shared/data.mjs    포켓몬·기술·행동·리액션 정의 ─ dex.mjs: 도감에서 추가하는 포켓몬, pokedex.mjs: 전국도감 표(자동 생성)
src/renderer/          포켓몬 애니메이션(pokemon.mjs), 기술 이펙트(fx.mjs), 음성(speech.mjs), 앱(app.mjs)
scripts/               첫 실행 준비(setup.ps1), 음성인식 설치(setup-whisper.ps1/.py), 오프라인 배포판(make-offline.ps1), 에셋 다운로드(fetch-assets, fetch-dex)
test/                  명령 해석 테스트 (npm test)
```

포켓몬은 모두 앱의 **🎒 파티**에서 바로 고를 수 있습니다. 소스에서 실행할 때 그림이 없으면 `npm run fetch-dex`(git 필요, 약 300MB)로 받으세요. 어떤 포켓몬의 울음소리·별칭·기술을 직접 다듬으려면 `src/shared/data.mjs`의 `POKEMON`에 한 줄 추가하고 `npm run fetch-assets`를 실행하세요.
